## Activity Description
This lab is intended to get you started with the basic Git/GitHub workflow, as well as understand a bit more about Git patch files.

### GitHub Fork/PR Steps
1. Go to https://github.com/mru-open-source/git-practice and [create your own fork](https://docs.github.com/en/pull-requests/how-tos/work-with-forks/fork-a-repo)
2. Clone a copy of *your fork* to your local machine
3. On your local machine: 
    1. Create and switch to a new branch, giving it a descriptive name like `pr-test`:
       ```bash
       git checkout -b pr-test
       ```
    2. Create a new file named `username.md`, where `username` is your GitHub username
    3. Populate the file with a quote of your choice, using [Markdown formatting](https://markdownformatting.com) as appropriate.
    4. Add and commit the changes to your local repository
    5. Add a link in the `README.md` file to the file you just created
    6. Commit the changes to your local repository and push to your fork
4. [Open a pull request](https://docs.github.com/en/pull-requests/how-tos/create-pull-requests/creating-a-pull-request-from-a-fork) (PR) in the original repo with your changes. This should be a single PR with at least **two commits** in it.

> Your PR will languish in this repo until next week, when we will go over resolving merge conflicts, squashing, merging, cherry picking, etc.

### Email Patch Steps
This time, we're going to pretend GitHub doesn't exist and work entirely on your local machine.

1. Switch back to your `main` branch with `git checkout main` (no `-b` flag this time — that tells Git to create a new branch)
2. Edit the file `email.md` where indicated.
3. Commit your changes as usual, but **don't push** this time
4. Create a `.patch` file with the following command:
   ```bash
   git format-patch origin/main
   ```
5. Open up the patch in a text editor and see if you can make sense of it
6. Email me the resulting patch file

That's it! Git has some fancy automated ways of sending email, but it involves setting up an app password in your Google account that IT services would probably frown upon.
